flickpick.tools#

The command surface: plain functions returning JSON-able values (SSOT for the CLI).

python -m flickpick <command> --help lists each command’s options; the same list, CLI_FUNCS, is what any later surface (MCP, HTTP) should project.

>>> [f.__name__ for f in CLI_FUNCS]
['build', 'recommend', 'evaluate']
