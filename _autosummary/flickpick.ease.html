flickpick.ease#

EASE (Steck 2019): a closed-form linear item-item model, sparsified to top-k.

Given a binary user x item matrix X:

G = X^T X + lambda I; P = G^-1; B = -P / diag(P) (column-wise); diag(B) = 0

A user’s score vector is then x B. B is dense, so each source row keeps only its topk largest positive weights (the recsys report, section 3, measured 98% of dense NDCG@100 at top-100 on MovieLens 32M). Rows of the result are source items, columns target items, and each row’s entries are sorted by descending weight, which is the order docs/artifact-format.md requires.
